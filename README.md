# Knucklebound

Phone VR ape parkour. Swing your real hands to climb and tag.

**Play:** https://fungames86.github.io/knucklebound/

This is **not** Gorilla Tag. Names, maps, and looks are original.

On iPhone: open the link in **Safari**, allow the camera, then drop the phone in a headset (print `print/knucklebound_viewer.stl` or use any cheap phone VR viewer with a camera hole). Safari → Share → Add to Home Screen if you want an icon.

Print notes: [print/README.md](print/README.md)
